# Mac global keybinds on Option (Hammerspoon, ~/dotfiles/hammerspoon/init.lua).
# Source: the mac-manager session. Same-hand allow-list for the firmware
# (users/tsah/tsah.c, is_opt_keybind_key). QWERTY key names.
H J K L    Opt: focus window left/down/up/right
           Cmd+Opt: snap left half / centered / maximize / right half
X          dismiss top notification
O          open top notification
1          Rex
2          Chrome
3          Slack
4          WhatsApp
5          Grok Bot
P          new Chrome window, personal profile
W          new Chrome window, work profile
U          screenshot selection and share
Q          close the focused window
Space      window hints (thumb key: counts as either hand, no allow-list entry needed)
# No Shift variants. Opt+arrows/Backspace and Opt+B/F/D/. stay unbound.
